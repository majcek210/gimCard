How to selfhost?

You can selfhost this software with cloning the repo then using either **Dockerfile** or **docker compose**

Option 1: Docker file

1. You will have to clone this repositiory

2. Build this image using the Dockerfile in a root directory

3. Deploy using docker

Option 2: Docker compose

1. You will have to clone this repository

2. Run the compose and docker will build the image for you.
