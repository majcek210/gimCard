How to selfhost?

If you want to selfhost this shitty software you can do this with options bellow (:

System requirements: docker

You will still need to import/load your env variables, see the .env.example for required variables.

Option 1: Dockerfile

This option is recommended for bare docker installations.

  1. You will have to clone this repository
    git clone https://github.com/majcek210/gimCard
  2. Go to repo directory
    cd gimCard
  3. Build the image
    docker build -t gimcard:latest .
  4. Run the image
    docker run -d -p 6767:6767 --name gimCard gimcard:latest

Option 2: Docker compose

For normal docker compose installations.

  1. You will have to clone this repository
    git clone https://github.com/majcek210/gimCard
  2. Go to repo directory
    cd gimCard
  3. Bring up docker compose service
    docker compose -f docker-compose.yml up

Option 3: coolify

If you selfhost and prefer some UI you probably use coolify. Here are the steps to configure this on coolify.

  1. New resource > select public repository
  2. Select your server
  3. Enter the repo URL(https://github.com/majcek210/gimCard)
  4. Coolify should automaticly detect it's settings, if not enter following:
    • Branch: main
    • Build pack: Docker Compose
    • Base directory: /
    • Compose file: /docker-compose.yml
